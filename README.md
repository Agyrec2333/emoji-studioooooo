# Emoji Studio

Lottie-редактор анимированных эмодзи Telegram (TGS).

- `public/` — редактор (статический сайт, публикуется через GitHub Pages).
- `server.js` — сервер с созданием пака через Bot API (нужен для раздела «Пак в Telegram»).

Локальный запуск: `node server.js`, затем http://localhost:3000.
